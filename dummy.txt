# Git Commands Available to Code Agent

## Viewing Repository Information
- list_directory: List directory contents in the repository
- read_file: Read the full contents of a single file
- git_log: View commit history for a branch or path
- git_diff: Compare two branches, tags, or commits
- list_branches: List branches in the repository
- list_pull_requests: List pull requests in the repository

## Branch Management
- create_branch: Create a new git branch from a base branch
- delete_branch: Delete a branch from the repository (cannot delete master or main)
- list_branches: List branches in the repository

## File Operations
- write_file: Create or update a file on a specified branch
- delete_file: Delete a file from a branch in the repository

## Commit Operations
- revert_commit: Create a revert commit that undoes changes from a specific commit
- cherry_pick_commit: Cherry-pick a commit onto a target branch

## Pull Request Management
- open_pull_request: Open a pull request in the repository
- close_pull_request: Close a pull request by its number
- merge_pull_request: Merge a pull request by its number (supports merge, squash, or rebase methods)

## Tagging & Releases
- create_tag: Create a git tag on a specific commit or branch
- create_release: Create a GitHub release, optionally creating a new tag

Total Commands Available: 18

## Limitations
- Cannot delete master or main branches
- All file operations create commits automatically
- Cannot perform low-level git operations directly
